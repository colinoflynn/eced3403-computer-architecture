Teaching notes
This is still a simplified model rather than a full ISA/timing-accurate Cortex-M implementation. The intent is to let students interactively explore hazards, forwarding, branch flushes, memory latency, and the effect of deeper pipelines. In this version, memory latency applies to loads and stores across the pipeline models. Setting latency to 1 should let a dependent use proceed as soon as the load completes, while higher values extend the visible stall.
