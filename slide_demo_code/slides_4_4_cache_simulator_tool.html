Cache Simulator Teaching Tool

This interactive demo is designed for teaching cache basics in computer architecture: hit/miss behavior, locality, associativity, block size, conflict misses, and AMAT.

Good classroom demos: sequential access, random access, strided access, repeated working sets, matrix-style row/column scans, and matrix-multiply loop-order comparisons.
